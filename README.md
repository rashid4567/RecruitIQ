## 📖 Overview

**RecruitFlow AI** is a full-stack, AI-powered recruitment platform designed to simplify and automate the entire hiring process. It enables recruiters to manage job postings, analyze resumes using AI, schedule interviews, track applications, and manage offer letters through a single, unified platform.

For candidates, the platform provides an intuitive experience to create profiles, upload resumes, apply for jobs, monitor application progress, and respond to interview invitations and offer letters.

The primary objective of the project is to reduce manual recruitment effort by leveraging Artificial Intelligence for resume screening and candidate evaluation, allowing recruiters to make faster and more informed hiring decisions.

---

## ❗ The Problem

Recruiters spend a huge amount of time manually reviewing resumes, tracking applications, scheduling interviews, and communicating with candidates. As application volume grows, these repetitive tasks become a bottleneck.

**RecruitFlow AI solves this** by automating resume analysis and organizing the entire recruitment pipeline in one place — improving speed, consistency, and efficiency.

## 🧠 AI Resume Analysis

AI-powered resume analysis is one of the core features of RecruitFlow AI.

When a candidate uploads a resume, the system:

1. Extracts structured information such as technical skills, work experience, and education.
2. Compares the extracted information with job requirements.
3. Generates an ATS-style score and candidate recommendations.
4. Stores the analysis so recruiters can quickly review and compare applicants.

This significantly reduces the time spent manually reviewing resumes while improving the consistency of candidate evaluation.

## 🏗️ Architecture

The backend follows **Clean Architecture** principles, keeping business logic fully decoupled from infrastructure concerns. This makes the codebase modular, scalable, and easy to test.

```
src/
├── domain/          # Core business entities & rules
├── application/      # Use cases / business logic
├── infrastructure/    # DB, external services, AI integration
└── interface/         # Controllers, routes, API layer
```

This layered structure keeps the system maintainable as new features are added.
This separation of concerns makes the application easier to maintain, test, and extend as new features are introduced.
